# Cannon Golf

`Cannon Golf` is a provisional working title for a planning-stage 3D physics
puzzle derived from the Paint Mountain runtime.

The copied Godot code, scenes, resources, assets, tests, and scripts are an
unchanged technical baseline. They still implement Paint Mountain and are not
evidence that the new game design has been implemented.

The current product definition lives in
[`project-specs/cannon-golf/PRD.md`](project-specs/cannon-golf/PRD.md). Visual
rules, research, decisions, open questions, and draft implementation tasks live
beside it. Do not infer the new product from legacy runtime names such as
`PaintSystem`, coverage, or the existing frontal Aim View.
