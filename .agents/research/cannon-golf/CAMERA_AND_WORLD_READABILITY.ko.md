# 카메라·목표 가독성 개선 요약

## Purpose

현재 문제와 다음 수정 방향을 짧게 설명한다. 이 문서는 설명용이다.
실제 작업 순서와 완료 기준은 연결된 실행계획이 관리하고, 제품 규칙은
`project-specs/cannon-golf/PRD.md`,
`project-specs/cannon-golf/DESIGN_RULES.md`,
`project-specs/cannon-golf/DECISIONS.md`가 관리한다.

## Sources

- 2026-08-15 코스 4 인게임 스냅샷
- 현재 카메라, 입력, 대포, 목표판, HUD, 월드 조명 코드
- 지금까지 확정된 카메라·목표·대포 위치 선택 규칙

## Findings

- 화면의 큰 흰 원은 지형이 아니라 지형에 붙여 놓은 밝은 목표판이다.
  하지만 낮고 넓어서 흰 지형처럼 보인다.
- 현재 청록 표식은 멀리서 보면 가는 선과 작은 점처럼 보인다.
- 카메라는 지형에 닿으면 이동 경로를 막는 대신 마지막 위치를 위로
  올린다. 이 때문에 절벽 옆이나 하늘 쪽으로 갑자기 튄다.
- 현재 대포 시점은 대포 뒤쪽의 외부 시점이다. 실제 발사 방향을 보는
  1인칭 시점이 아니다.
- 현재 발사는 카메라를 바꾸지 않는다. 최신 요청과 반대다.

## Recommendations

1. 전체 보기 하나에서 드래그·회전·확대를 처리한다. 카메라가 지형에
   닿으면 위로 튀지 않고, 지형 앞에서 이동 거리를 줄인다.
2. 대포 시점은 선택한 대포 자리에서 실제 발사 방향을 보는 1인칭으로
   바꾼다. 화면 중앙의 작은 조준 표시와 대포 주변의 방향 화살표로
   회전을 보여준다.
3. 발사하면 새 공을 자동으로 따라간다. `Tab`을 누르면 발사 직전의
   전체 보기 또는 대포 시점으로 정확히 돌아간다.
4. 흰 목표판을 없앤다. 목표판은 산과 어울리는 어두운 녹색 바닥과
   진한 테두리를 사용한다. 목표판의 깃발은 유지한다. 모든 미완료 목표
   위에는 주변 봉우리보다 높은 위치에 굵은 주황색 3D 아래 화살표를
   추가한다.
5. 이 게임에는 “다음 목표”가 없다. 보이는 모든 미완료 목표는 같은
   중요도로 표시하고, 플레이어가 공략 순서를 고른다.

## Limitations

- 이번 계획은 목표 위치, 지형 생성 규칙, 준비된 맵 파일을 바꾸지
  않는다.
- 새 패널이나 설명 상자를 늘리지 않는다.
- 개발 중에는 긴 성능·물리 인증 테스트를 돌리지 않는다. 기능 구현을
  모두 끝낸 뒤 실행 확인과 최종 화면 확인만 한 번 진행한다.
